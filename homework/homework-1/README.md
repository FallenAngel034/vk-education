# Домашнее задание №1 — тестирование REST API

Выбранный вариант: написать тесты для REST API.

API: Open-Meteo Geocoding  
Метод и адрес: `GET https://geocoding-api.open-meteo.com/v1/search`

## Сценарии

1. Поиск Paris во Франции с `count=1`: статус 200, один результат, название Paris, код страны FR. Проверяется нижняя допустимая граница `count`.
2. Поиск несуществующего города: статус 200, результатов нет.
3. `count=0`: статус 400, признак ошибки и непустое текстовое объяснение.
4. `count=100`: статус 200, от 1 до 100 результатов. Проверяется верхняя допустимая граница.
5. `count=101`: статус 400, признак ошибки и непустое текстовое объяснение.
6. Отсутствует обязательный параметр `name`: статус 400, признак ошибки и непустое текстовое объяснение.
7. Проверка структуры ответа: формат JSON, типы полей города и допустимые диапазоны координат.
